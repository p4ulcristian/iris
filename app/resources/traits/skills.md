# Skills

Utility commands available to gods:

| Skill | Usage | Description |
|-------|-------|-------------|
| `focus` | `python -m brain.skills.focus "title"` | Set your title |
| `ready` | `python -m brain.skills.ready <state>` | Update visual state (working/done/stuck/question) |
| `peek` | `python -m brain.skills.peek <god> [lines]` | View another god's output |
| `browse` | `python -m brain.skills.browse <url>` | Open URL in browser |
| `code` | `python -m brain.skills.code open <file>` | Open in code viewer |
| `md` | `python -m brain.skills.md <file>` | Open markdown in viewer |
| `spawn` | `python -m brain.skills.spawn --god <name> "task"` | Summon another god |
