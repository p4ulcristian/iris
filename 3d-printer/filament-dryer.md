# Filament Dryer

DIY filament dryer built between two pantry shelves.

**Target temps:** 50-60°C (works for PLA and PETG)
**Capacity:** 6-12 spools

## Parts List

### Heating
- [ ] Silicone heating mats 2x 80-100W (~20,000-40,000 Ft each)
- [ ] Thermostat controller W1209 (~1,400-4,000 Ft)

### Ventilation
- [ ] 12V fan 80mm (~1,500-5,000 Ft)

### Monitoring
- [ ] Digital hygrometer (~800-5,000 Ft)

### Insulation (to protect thin wood shelves)
- [ ] Aluminum foil (line inside surfaces, shiny side in)
- [ ] Ceramic tile or metal plate (under heating mat)
- [ ] Cork sheet or foam insulation (optional, for better heat retention)

### Extras
- [ ] Silica gel / desiccant packets (~1,000-2,000 Ft)
- [ ] 12V power supply (~2,000-5,000 Ft)
- [ ] Wiring / connectors (~1,000-2,000 Ft)
- [ ] Enclosure panels (plywood, acrylic) (~1,000-3,000 Ft)

**Estimated total: ~25,000-70,000 Ft**

## Build Steps

### 1. Measure & Plan
- [ ] Measure space between shelves (height, width, depth)
- [ ] Decide how many spools to fit
- [ ] Sketch layout

### 2. Insulate the Shelves
- [ ] Line inside surfaces with aluminum foil (shiny side in)
- [ ] Place ceramic tile or metal plate where heating mats will go
- [ ] Add cork or foam insulation if needed for better heat retention

### 3. Build the Enclosure
- [ ] Use existing shelves as top/bottom
- [ ] Add side panels (plywood, acrylic, or cardboard + foil for insulation)
- [ ] Make a door/front panel for access
- [ ] Seal gaps with weather stripping

### 4. Install Heating
- [ ] Mount 2x silicone heating mats (bottom and/or sides)
- [ ] Wire mats to thermostat controller (W1209)
- [ ] Place thermostat probe inside box, near filament area

### 5. Add Ventilation
- [ ] Mount small fan inside for air circulation
- [ ] Wire fan to power supply

### 6. Set Up Monitoring
- [ ] Place hygrometer inside (visible through door)
- [ ] Add silica gel packets at the bottom

### 7. Test & Calibrate
- [ ] Run empty, check temps at different spots
- [ ] Adjust thermostat (aim for 50-55°C)
- [ ] Verify temperature holds stable

### 8. First Real Test
- [ ] Dry a spool for 4-6 hours
- [ ] Print test to check improvement (less popping/stringing)

## Notes

- PLA drying: 40-50°C, 4-6 hours
- PETG drying: 55-65°C, 4-6 hours
