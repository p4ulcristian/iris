# iris — memories

Long-term facts iris should carry between conversations: who Paul is, his
preferences, standing decisions, and details about Gaia/Olympus that aren't
derivable from the code or git history.

One fact per file, kebab-case filename, short and declarative. Keep entries
true and current — delete a memory when it stops being accurate rather than
letting it rot. This folder is the durable counterpart to a single session's
context.
