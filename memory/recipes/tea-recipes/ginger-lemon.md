# Gyömbéres-Citromos Tea

## Hozzávalók
- Friss gyömbér (2-3 cm szelet, felszeletelve)
- Fél citrom leve
- Méz ízlés szerint
- Opcionális: kis kurkuma

## Elkészítés
1. A gyömbért vékony szeletekre vágd
2. Öntsd le forró vízzel
3. Hagyd ázni 5-10 percig
4. Add hozzá a citromlevet
5. Mézzel édesítsd (ne forró teába, csak langyosba)

## Egészségügyi hatások
- Immunrendszer erősítése
- Emésztéssegítő
- Hányinger ellen
- Megfázás tüneteire
- Gyulladáscsökkentő
